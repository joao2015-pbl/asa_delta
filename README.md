# asa_delta
o painel do projeto asa delta
O Projeto Asa Delta é uma plataforma unificada e robusta de Open-Source Intelligence (OSINT), construída em Python para realizar consultas complexas e enriquecimento de dados sobre indivíduos e entidades brasileiras.

Como executar o painel OSINT

    Extraia o arquivo .zip utilizando o descompactador de sua preferência.

    Abra a pasta extraída.

    Inicie o Terminal Linux

Execute o arquivo principal com o comando:

python asadelta.py

        Após a execução, o painel será iniciado automaticamente.

Recursos do Painel

Interface 100% em português, desenvolvida para oferecer uma experiência simples e intuitiva.

Utilização de APIs públicas, garantindo acesso às informações de forma prática e eficiente.

Sistema de Ajuda Integrado, com suporte por palavras-chave. Basta digitar sua dúvida (ex.: "como funciona o DDD") para receber uma resposta objetiva e direta baseada na documentação disponível.

Respostas otimizadas para fornecer as informações de forma rápida, clara e sem conteúdo desnecessário.
